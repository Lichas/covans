# ROADMAP — Covan 开发计划

> 本文档只放未完成项。当前已实现的行为见 [SPEC](SPEC.md)，历史版本见 [CHANGELOG](../CHANGELOG.md)。

## P0 · 信任与核心对话

### Provider 密钥保护

- 用 Electron `safeStorage` 加密新保存的 API Key。
- 为现有 SQLite 明文值提供可回滚 migration。
- 补充锁定/解锁、无系统密钥环境与数据库备份回归。

### 消息编辑、重新生成与分支

- 明确用户消息、回复轮次和分支的数据模型。
- 重试不再重复插入用户消息，支持在多个回复间切换。
- 导出时能区分当前分支和全部分支。

### Agent 工具活动可见化

- 将工作区读写、资料修改、生图和 Agent 私聊展示为可折叠活动记录。
- 显示输入、结果、失败和停止状态，同时隐藏密钥与内部敏感参数。

## P1 · 管理与成本

### 全文搜索与会话归档

- SQLite FTS 搜索会话名、消息与 Bot 名称。
- 归档会话不删数据，可恢复；删除与清空仍保持独立语义。

### 群聊成本与节奏控制

- 在群设置中提供每轮最大回复成员数、超时与预算提示。
- 在不暴露内部调度的前提下，给出本轮使用的 Provider/模型和 Token 摘要。

### 文件附件

- 在现有多图基础上支持 PDF、文本和代码文件。
- 增加类型/大小检查、本地预览、模型能力提示和导出路径。

### 记忆相关性检索

- 评估以本地 embedding 或用户 Provider 为当前会话检索相关记忆，替代纯时间窗口。
- 新索引必须使用 additive migration，保留手动记忆、去重与无 embedding 时的降级路径。

## P2 · 阅读与发布

- 数学公式、Mermaid 图、字体大小和更细的阅读偏好。
- macOS 签名/公证、Windows 安装包和自动更新。
- 发布前建立 CI：typecheck、smoke、核心 Electron UI 回归和构建。

## 计划维护规则

- 新候选项先写问题与验收结果，不在 Roadmap 中预先写未确定的 API 细节。
- 开始实现时，将具体契约写入 SPEC；完成后从本文档移除并更新 CHANGELOG。
- 优先级由用户价值、数据风险、回归范围和 Provider 成本共同决定。
