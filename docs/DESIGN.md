# DESIGN — Covan 体验与交互规范

> 本文档记录稳定的设计决策，不记录开发日志。可观测行为和边界条件以 [SPEC](SPEC.md) 为准，未完成项放在 [ROADMAP](ROADMAP.md)。

## 1. 设计目标

- **先对话，后设置**：主界面应把注意力留给消息，设置按需展开。
- **人格可识别**：名称、头像、人设、记忆和状态共同形成 Bot 身份。
- **多 Agent 但不喧闹**：让用户看到谁在思考，但不把内部调度文字混入聊天。
- **本地可控**：错误、停止、导出、清空和数据去向都必须明确可见。
- **克制而温暖**：暖白/炭灰底色、低饱和绿点缀、留白分层，避免过多高饱和色和装饰性卡片。

## 2. 信息架构

### 左栏：对象与会话

- 顶部是 Covan 入口、新建和搜索；底部「关于我」显示用户头像或名字首字占位。
- 最多 3 个置顶 Bot 以圆形头像显示；只能通过单聊列表项右键置顶/取消置顶。
- 会话列表保留名称、预览、时间和未读点；群聊用叠头像和成员数区分。
- 群聊列表项右键提供「删除群聊」；使用危险色并二次确认，文案明确说明消息和 Agent 私聊记录不可恢复。
- 底部固定为「关于我」、「我的 Bot」、「新建群聊」和「设置」。

### 中栏：对话

- 阅读列限宽，长文、代码和表格优先保证可读性。
- 用户消息紧凑对齐右侧；Bot 消息使用宽阅读区，明确显示作者和时间。
- 只展示用户和 Agent 实际交流内容。群聊调度、顺序判断等内部状态不写入消息流。
- 上翻后不强制跳回底部；新消息通过「回到最新」恢复。

### 右栏：当前对象设置

- 单聊展示 Bot 的「设定 / 记忆 / 工作区 / 模型」，模型 Tab 固定在最后。
- 记忆页以全部 / 短时 / 场景 / 语义 / 长期筛选，顶部优先显示当前场景的极短摘要与摘要状态；原文证据单独标识，不伪装成摘要。条目显示归纳或原话、作者、参与者、来源和时间；新摘要即时更新。失败时保留上一次并提供刷新入口；删除会一并忘记相关归纳，手动添加默认长期；列表分批展示以保持侧栏响应。
- 群聊齿轮展示群成员回复机制；点击消息中某位成员头像时，可临时检视该 Bot 设置。
- 面板默认收起，保持中栏阅读宽度。

## 3. 消息与输入

- Markdown 支持标题、列表、引用、GFM 表格、任务列表、行内代码、行内/块级 LaTeX 公式和高亮代码块。
- 消息操作保持低干扰：复制、引用、重试在消息附近呈现，错误直接内联显示。
- Composer 是浮动圆角输入框；Enter 发送，Shift+Enter 换行，必须保护中文输入法组词。
- 图片支持多选、粘贴、拖放、发送前移除和消息内放大。
- Bot 真实写入或编辑工作区文件后，在回复正文下方显示低干扰的「交付文件」卡片：先概括本轮文件数，再逐项显示文件名、生成/更新状态和大小；提供就地文本预览、系统定位与打开工作区。卡片来自工具执行结果，不把回复中的普通文件名或代码块误判为产物。
- 每个会话的草稿独立保存；切换会话或重启不丢失。
- 私聊的「自然追问」默认开启但可在设置关闭：较长内容可按即时聊天节奏分成最多 3 个各自完整的语义段；续发必须带来新内容或明确问题，完整回答后保持安静，不复述，也不出现“下一条来了”等调度元话术。
- 通用设置提供默认关闭的「本地观测日志」：紧邻开关解释记录项和隐私边界，并提供打开日志目录按钮；不得把聊天正文或密钥包装成所谓调试信息。

## 4. 群聊反馈

- 「主动回复」时，所有成员并发判断。输入框上方用动画小头像显示正在思考或回复的成员，用户仍可继续发送。
- 「顺序回复」时，成员依次判断和发言，但聊天区不显示“正在安排”之类文案。
- 首轮后可静默延展至最多 5 轮；只有有新信息或具体回应才进入下一轮，无人继续时自然收束，不能为了轮次重复观点。
- 准备状态的动画应轻量、不推动主消息区布局，并遵守系统减少动效偏好。
- 停止是全轮次行为：当前已输出内容保留，尚未开始的判断或回复取消。

## 5. Bot 身份与 Agent 私聊

- 名称和头像修改后要在列表、聊天、置顶区和私聊浮窗同步更新。
- 「关于我」每次打开进入「我的资料」，内容偏好卡置于头像和资料表单之前，紧凑窗口首屏可见，提供默认关闭的「接受成熟内容 · 18+」开关，说明泳装生活照和非露骨成年伴侣风格的影响；开关立即保存，不顺带提交其他未保存资料。
- 「关于我」提供紧凑的默认头像选择与自定义上传；选择立即同步到侧边栏。头像是本机界面资料，不作为文本提示词发送给模型。
- 创建 Bot 时先选择性别（默认 ♀）与对应头像，6 张候选紧凑排布，勾选与底色共同表达选中态。
- 更换头像仅保留点击头像入口，hover 与键盘焦点显示编辑提示；弹窗以形象预览、来源切换、内容、操作区分层。来源顺序为「内置头像 / 自定义上传 / AI 生图」，默认内置；内置先预览再应用，上传明确选定即应用，AI 页允许切换本地插画且如实说明服务要求。
- 生活照独立标签排在最左侧，后面依次为设定、记忆、工作区、模型；匹配内置头像的照片从标签页顶部展示，以圆角竖幅照片、柔和渐变、序号和轻量轮播控件展示；无照片时显示简洁说明；五个标签均分侧栏宽度，不横向溢出。自动播放可以暂停，悬停与焦点进入暂缓，遵守减少动效偏好；紧凑窗口可滚动访问全部内容。
- Agent 咨询另一位 Agent 后，在来源消息附近插入轻量记录卡；详情在浮窗展开，不抢占主聊天流。

## 6. 可用性与验收

- 关键图标按钮必须有 `aria-label` 和可理解的 tooltip。
- 弹窗支持 Esc 关闭和焦点限制；危险操作要有明确颜色与确认。
- 浅色、深色和 960×640 紧凑窗口都不应出现页面级横向滚动。
- 重要交互使用独立临时 profile 的 Electron UI 测试验收，截图产物写入 `artifacts/`，不进入 Git。
