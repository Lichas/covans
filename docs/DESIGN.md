# DESIGN — Covan 体验与交互规范

> 本文档记录稳定的设计决策，不记录开发日志。可观测行为和边界条件以 [SPEC](SPEC.md) 为准，未完成项放在 [ROADMAP](ROADMAP.md)。

## 1. 设计目标

- 应用图标使用随项目分发的渐变人像图标；macOS Dock 与打包应用保持一致。

- **先对话，后设置**：主界面应把注意力留给消息，设置按需展开。
- **人格可识别**：名称、头像、人设、记忆和状态共同形成 Bot 身份。
- **多 Agent 但不喧闹**：让用户看到谁在思考，但不把内部调度文字混入聊天。

- 引用回复使用标准 Lucide Quote 图标；Composer 内引用以低对比背景、左色条、作者和摘录呈现，与正文分开，可取消。引用和长正文保持滚动，隐藏滚动条。
- 回复操作栏含 Bug 图标，生成中也可复制诊断标识。设置 Debug 页使用紧凑元数据、事件表和诊断结果区，先加载本地报告，再由用户选择模型分析；缺失日志、发送的数据范围和分析状态可见。
- **本地可控**：错误、停止、导出、清空和数据去向都必须明确可见。
- **通透而安静**：冰蓝浅色 / 深海蓝深色底色，静态蓝色光晕建立空间感。导航、输入区和弹窗采用半透明磨砂、细高光边框与柔和阴影；正文保持高对比、克制留白，不在阅读区堆叠装饰。首页使用不可交互的抽象流线作为品牌背景。

## 2. 信息架构

### 左栏：对象与会话

- 顶部是 Covan 入口、新建和搜索；底部「关于我」显示用户头像或名字首字占位。
- 最多 3 个置顶 Bot 以圆形头像显示；只能通过单聊列表项右键置顶/取消置顶。
- 会话列表保留名称、预览、时间和未读点；群聊用叠头像和成员数区分。
- 群聊列表项右键提供「删除群聊」；使用危险色并二次确认，文案明确说明消息和 Agent 私聊记录不可恢复。
- 搜索下方提供「我的 Bot」「新建群聊」快捷入口。底部固定个人头像、名称、问候语与设置；头像入口打开「关于我」。下方为浅色 / 深色 / 跟随系统图标分段控件，名称、tooltip、键盘焦点和选中态清晰；设置中用三张配色预览卡呈现同一主题状态。

### 中栏：对话

- 阅读列限宽，长文、代码和表格优先保证可读性。
- 单聊采用气泡式布局：用户消息为深色胶囊、靠右且贴合内容；Bot 消息为浅色玻璃圆角块、靠左且按内容收缩（宽内容最多占 88%），作者头像、名称与时间收进气泡上方的一枚悬浮胶囊。群聊沿用宽阅读区，不套用单聊气泡。
- 单聊消息间距略宽于群聊，第一条消息靠近顶部；错误回复整块使用淡红底，不用单独的左竖线。
- 任意会话中栏可使用内置场景照片作为背景；顶部栏、消息气泡和日期分隔使用半透明磨砂层确保文字在浅色/深色主题下都可读。
- 只展示用户和 Agent 实际交流内容。群聊调度、顺序判断等内部状态不写入消息流。
- 聊天顶部用 `MessageSquarePlus` 图标提供「开始新话题」，群聊与私聊位置一致。当前话题达到 40 条消息或隔天续聊时，用图标提示点和 Composer 上方的单行提示条提醒；提醒不自动执行。
- 私聊 Bot 在准备回复、流式输出或执行工具时，顶部头像以一圈低饱和多色渐变环轻量旋转；这是状态反馈而非可操作控件，停止后立即消失，并遵守系统减少动效偏好。
- 上翻后不强制跳回底部；新消息通过「回到最新」恢复。

### 右栏：当前对象设置

- 单聊展示 Bot 的「生活照 / 设定 / 记忆 / 工作区 / 定时 / 模型 / 扩展」；「定时」只列出当前 Bot 的任务，「扩展」只编辑当前 Bot 装配。头部为居中布局：大尺寸圆形头像、居中名称与描述，下方仍是七个功能标签页；点头像即可更换。
- 设置使用左侧分类、右侧内容的 macOS 风格布局。MCP、Skills 与 Debug 都是一级分类并列显示；MCP / Skills 页面提供安装、测试、编辑、预览、停用与卸载。Bot 页显示装配状态，并提供直接打开对应全局管理页的图标入口。工具清单默认折叠，连接状态标注为最近测试结果；安装编辑使用平铺表单，不嵌套装饰卡片。认证值只在输入时可见，不回填。
- 设置弹窗提供全局「定时任务」页，按 Bot 汇总。任务行用时钟、计划、模型来源、下次执行/最近错误和启用开关组成；立即执行、编辑、删除使用图标按钮。编辑器内可选单次或重复 Cron、时区和模型覆盖，结果投递目标会话。
- Provider 的图标使用各厂商的图形标识，不在图标中放入名称、首字母或缩写；兼容端点与本地 Mock 保持中性符号，避免把用户的自定义服务误标为某一厂商。
- 设定页的人设 System Prompt 默认展示 Markdown 预览，右上角铅笔进入编辑。预览自动填满设定页剩余高度，底部留 20px 边距；编辑态固定 380px 高等宽语法高亮区域，由侧栏自身滚动而不是压缩编辑区（居中头部占位更大后，撑满剩余空间会把它压到约 245px），完成/取消按钮固定在编辑区下方；预览与编辑都保持侧栏内滚动，不挤压聊天列。
- 记忆页以全部 / 短时 / 场景 / 语义 / 长期筛选，顶部固定显示当前短时窗口与场景摘要；短时条目标明窗口消息数，每窗最多 10 条且首尾不超过 15 分钟。原文证据单独标识，不伪装成摘要。条目显示归纳或原话、作者、参与者、来源和时间；新摘要即时更新。失败时保留上一次有效结果并提供刷新入口；删除会一并忘记相关归纳，手动添加默认长期；列表分批展示以保持侧栏响应。
- 群聊齿轮展示群成员回复机制与完整背景选择；单聊背景选择放在 Bot 设定页的人设前方，默认以当前背景预览卡和「更换」入口紧凑呈现，展开后显示图库，强调它是当前会话外观而非 Bot 人设。点击群消息中某位成员头像时，可临时检视该 Bot 设置。
- 面板默认收起，保持中栏阅读宽度。

## 3. 消息与输入

- Markdown 支持标题、列表、引用、GFM 表格、任务列表、行内代码、行内/块级 LaTeX 公式和高亮代码块。
- 普通消息正文和 TXT 产物预览使用系统 UI 中文黑体栈；代码块、代码文件预览和文件名使用等宽字体，避免正文阅读区域显得像代码编辑器。
- 消息操作保持低干扰：复制、引用、重试在消息附近呈现，错误直接内联显示。
- 开始新话题必须二次确认，说明完整历史仍保留、模型将改用摘要与新消息，以及记忆/产物/任务不受影响。执行中按钮显示进度且不可关闭弹窗；失败在弹窗内联展示，不插入分界。成功后用两侧细线和短文案展示话题边界，不使用普通消息气泡。
- Composer 是浮动玻璃输入框，上方为完整宽度的文本区，下方左侧放附件与提及、右侧放发送与停止；Enter 发送，Shift+Enter 换行，必须保护中文输入法组词。
- 图片支持多选、粘贴、拖放、发送前移除和消息内放大。
- Bot 真实写入或编辑工作区文件后，在回复正文下方显示低干扰的「交付文件」卡片：先概括本轮文件数，再逐项显示文件名、生成/更新状态和大小；点击预览打开右侧产物预览窗，Markdown、HTML、TXT、代码、图片和 PDF 按各自形态展示，卡片内不展开代码块；预览窗左边缘可拖拽调整宽度，同时保留系统定位与打开工作区。卡片来自工具执行结果，不把回复中的普通文件名或代码块误判为产物。
- 每个会话的草稿独立保存；切换会话或重启不丢失。
- 私聊的「自然追问」默认开启但可在设置关闭：较长内容可按即时聊天节奏分成最多 3 个各自完整的语义段；续发必须带来新内容或明确问题，完整回答后保持安静，不复述，也不出现“下一条来了”等调度元话术。
- Bot「模型」页用选择框配置响应决策策略：默认「自动」在 Jev 已配置时优先使用，另可强制传统 LLM 或 Jev；说明该设置同时作用于群聊发言和私聊续发、正文模型不变、失败会回退。全局 TypeSafe Key、Jev 模型与置信度阈值放在「设置 → Bot」，密钥输入只显示已保存状态，不回显明文。
- 通用设置提供默认关闭的「本地观测日志」：紧邻开关解释记录项和隐私边界，并提供打开日志目录按钮；不得把聊天正文或密钥包装成所谓调试信息。
- 「运行方式」在选择 Provider 之前呈现：默认「模型 API（Provider）」，可切换为「本地 Codex CLI」或「本地 Claude CLI」。选中本地 CLI 后就地展开可执行文件、检测结果与文件权限三项，并把 Provider 改标注为「判断用，可选」；检测结果单行显示「已安装 · 版本 x.y.z」，下一行灰色显示实际路径，失败时在同一行给出可读原因，不使用弹窗或红色告警块。新建 Bot 与 Bot 模型页复用同一组字段与文案。

## 4. 群聊反馈

- 「主动回复」时，所有成员并发判断。输入框上方用动画小头像显示正在思考或回复的成员。
- 「顺序回复」时，成员依次判断和发言，但聊天区不显示“正在安排”之类文案。
- 两种群聊模式在生成期间都同时保留发送与停止按钮。用户的补充消息立即显示，正在思考的成员改用最新上下文；正在输出的内容保持连续。
- 首轮后可静默延展至最多 5 轮；只有有新信息或具体回应才进入下一轮，无人继续时自然收束，不能为了轮次重复观点。
- 准备状态的动画应轻量、不推动主消息区布局，并遵守系统减少动效偏好。
- 停止是全轮次行为：当前已输出内容保留，尚未开始的判断或回复取消。

## 5. Bot 身份与 Agent 私聊

- 名称和头像修改后要在列表、聊天、置顶区和私聊浮窗同步更新。
- 「关于我」每次打开进入「我的资料」，内容偏好卡置于头像和资料表单之前，紧凑窗口首屏可见，提供默认关闭的「接受成熟内容 · 18+」开关，说明泳装生活照和非露骨成年伴侣风格的影响；开关立即保存，不顺带提交其他未保存资料。
- 「关于我」提供紧凑的默认头像选择与自定义上传；选择立即同步到侧边栏。头像是本机界面资料，不作为文本提示词发送给模型。
- 创建 Bot 时先选择性别（默认 ♀）与对应头像，6 张候选紧凑排布，勾选与底色共同表达选中态。
- 更换头像仅保留点击头像入口，hover 与键盘焦点显示编辑提示；弹窗以形象预览、来源切换、内容、操作区分层。来源顺序为「内置头像 / 自定义上传 / AI 生图」，默认内置；内置先预览再应用，上传明确选定即应用，AI 页允许切换本地插画且如实说明服务要求。
- 生活照独立标签排在最左侧；匹配内置头像的照片从标签页顶部展示，以圆角竖幅照片、柔和渐变、序号和轻量轮播控件展示；无照片时显示简洁说明。所有标签均分侧栏宽度，不横向溢出。自动播放可以暂停，悬停与焦点进入暂缓，遵守减少动效偏好；紧凑窗口可滚动访问全部内容。
- Agent 咨询另一位 Agent 后，在来源消息附近插入轻量记录卡；详情在浮窗展开，不抢占主聊天流。

## 6. 可用性与验收

- 关键图标按钮必须有 `aria-label` 和可理解的 tooltip。
- 弹窗支持 Esc 关闭和焦点限制；危险操作要有明确颜色与确认。
- 浅色、深色和 960×640 紧凑窗口都不应出现页面级横向滚动。
- 重要交互使用独立临时 profile 的 Electron UI 测试验收，截图产物写入 `artifacts/`，不进入 Git。
